💡 Notas para el presentador
  • + con un string concatena; - * / convierten a número.
  • Los arrays se convierten a string ([] → ""); los objetos a "[object Object]".
  • null >= 0 es true pero null == 0 es false: los operadores relacionales convierten null en 0, == no.
  • El de la banana: +"a" es NaN → "baNaNa".
