Ejercicios: Objetos y arrays

Reto: getAdultNames(people) 🏆

← Volver a la diapositiva

Dado un array de objetos { name, age }, devuelve los nombres de todas las personas con 18 años o más, ordenados alfabéticamente.

Pista: encadena filter → map → sort.

💡 Notas para el presentador
  • Buen momento para mostrar que la solución es una sola cadena legible: sin bucles ni variables temporales.
