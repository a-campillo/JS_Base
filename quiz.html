Quiz final 🧠

Puntaje: 0 / 6

1. typeof null devuelve…

Un bug histórico que se mantiene por compatibilidad.

2. ¿Qué declaración tiene alcance de bloque y no se puede reasignar?

const, aunque el objeto al que apunta todavía se puede modificar.

3. 0 ?? 5 da como resultado…

?? solo usa el valor alternativo con null/undefined. (0 || 5 daría 5.)

4. "2" + 2 * "2" da como resultado…

* se evalúa primero y convierte a números: 2 * "2" → 4. Luego "2" + 4 concatena → "24".

5. [1, 2, 3].map(n => n * 2) devuelve…

map devuelve un array nuevo con cada elemento transformado.

6. ¿Qué devuelve g() la tercera vez?

La función flecha devuelta forma un closure sobre c, así que la cuenta se conserva entre llamadas.
